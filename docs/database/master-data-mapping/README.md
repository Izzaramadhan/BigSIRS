# Audit dan Perencanaan Master Data BigSIRS

Dokumentasi ini berisi hasil audit dan perencanaan tahap awal untuk fondasi Master Data sistem BigSIRS (Rawat Jalan & Logistik).

## Daftar Dokumen

1. [Review Model Existing](existing-model-review.md) - Analisis model dan tabel referensi yang sudah ada di repositori.
2. [Inventaris Master Data](inventory.md) - Matriks daftar lengkap kandidat master data berdasarkan domain.
3. [Mapping Tabel Legacy](legacy-table-mapping.md) - Analisis relasi dan pemetaan dari database lama (SIMRS lama).
4. [Urutan Dependensi](dependency-order.md) - Urutan logis implementasi berdasarkan hierarki relasi data.
5. [Rencana Implementasi](implementation-plan.md) - Rekomendasi scope untuk slice (tahap) implementasi pertama.
6. [Pertanyaan untuk Supervisor](questions-for-supervisor.md) - Daftar hal-hal yang memerlukan klarifikasi atau konfirmasi dari supervisor/stakeholder.

## Tujuan
Memastikan pembuatan master data dilakukan secara terstruktur, meminimalisir duplikasi, serta memperhatikan dependensi antar entitas sebelum tahap implementasi kode dilakukan.
